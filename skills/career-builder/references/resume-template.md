# Resume and profile templates

## One-page student resume

```
NAME
City | email | phone | github.com/handle | linkedin.com/in/handle | portfolio link

EDUCATION
B.Tech, Computer Science, University Name            2025 - 2029
CGPA: x.xx (only if it helps)  | Relevant courses: ...

PROJECTS
Project Name - one line on what it is            link
- Built <what> using <stack>, which <result or user number>.
- <Hard problem> solved by <approach>.

SKILLS
Languages: ...   Frameworks: ...   Tools: ...

EXPERIENCE / ACTIVITIES
Role, Organisation                                  dates
- <action> <what> <result>

ACHIEVEMENTS
- Hackathon, rank, or certificate that matters for the target role
```

Projects come before experience for students. Two to four projects, most relevant first.

## Bullet formula

Action verb + what you built or did + how + result.

| Weak | Strong |
|---|---|
| Worked on a music bot | Built a Telegram music bot in Python with a custom download API, used by 300+ group members |
| Made a website | Built a responsive trading portfolio site with an admin panel on MongoDB, deployed on Vercel |
| Knows Python | (Remove. Show it through a project bullet instead) |

Only use numbers the person gives you. If there is no number, describe scope or difficulty instead.

## LinkedIn

- Headline: role you want + focus + proof. Example: "CS student | Backend and APIs in Python | Building self-hosted AI tools"
- About: 4 to 6 short lines in first person. What you build, one project with a result, what you are looking for.
- Featured: the 2 or 3 best projects with links and a screenshot.

## Interview answers (STAR)

Situation, Task, Action, Result. Prepare one story each for: a hard bug, a project you led, a mistake you fixed, working with a team, learning something fast.

## Project write-up (for README or portfolio)

Problem, what you built, stack, one hard part and how you solved it, result, what you would do next.

## Before sending

- Every line can be explained in an interview.
- Same date format and tense throughout.
- File named `Firstname_Lastname_Resume.pdf`.
- Plain layout, no tables or images in the main resume, so applicant tracking systems can read it.
