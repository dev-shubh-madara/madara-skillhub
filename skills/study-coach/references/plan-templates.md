# Plan templates and methods

## Day plan format

```
Day 1 (Mon) - 3 h
  1.5 h  Unit 2: diode basics (weak)          - learn + 5 questions
  1.0 h  Unit 1: wave function (medium)       - 10 practice questions
  0.5 h  Recall: write yesterday's formulas from memory
Day 7 (Sun) - buffer: catch up or rest
```

Rules: every day has active practice, not only reading; every seventh day is a buffer; the last two or three days are only mocks and revision.

## Spaced revision

Bring a topic back after 1 day, 3 days, 7 days and 14 days. If the learner gets it wrong at any step, restart that topic at 1 day.

## Active recall methods

- Close the book and write what you remember, then check.
- Make three questions from each page and answer them the next day.
- Explain the topic out loud in two minutes, as if to a junior.
- For formulas: write the derivation outline, not just the final line.

## Unit test template

```
Unit test: <unit>   Time: <same per-mark time as the real exam>
Section A  2 marks x 5   definitions and short answers
Section B  5 marks x 2   derivation or numerical with steps
Section C  10 marks x 1  long answer
```

Match the real paper pattern if the learner shares it. Report: score, time used, three costliest mistakes with the fix for each.

## Numerical answers

Write given values with units, the formula, substitution, the result with units and sensible significant figures, and a one-line check (is the size reasonable, do units match). Marks are often given per step, so showing steps protects marks even when the final number is off.

## When time is short

Rank topics by marks weight times weakness. Do the top items first. Drop the lowest item rather than skimming everything.
